Документация описывает SGC Loading Screen 2.5.0, версия скоро появится на FAB. Сейчас на FAB — 1.0.0.

Диагностика

Страница сопоставляет симптом с проверкой и действием. Для консоли и оверлея нужна сборка для разработки.

Инструменты

Заголовок раздела «Инструменты»
  • Консоль: SGC.LoadingScreen.Why печатает состояние экрана и все удержания.
  • В оверлее метрик есть строка Holds:: тег, владелец и возраст каждого удержания.
  • Категория лога LogSGCLoadingScreen. Для подробностей включите Verbose.
  • -NoLoadingScreen (не-shipping) выключает экран. Так видно, виноват ли экран.

Симптомы

Заголовок раздела «Симптомы»
Симптом Проверка Действие
Экран не закрывается Выполните SGC.LoadingScreen.Why. Найдите удержание в списке. Снимите удержание через Release Loading Screen Hold из объекта, который его поставил. Удержание дольше 30 с также даёт предупреждение в логе.
Экран не закрывается в ручном режиме Сборка для разработки пишет в лог напоминание, что режим ждёт Dismiss Loading Screen. Вызовите Dismiss Loading Screen или задайте Max Visible Secs.
Экран не закрывается после 100 % Проверьте Continue On Input. Нажмите клавишу, кликните или коснитесь. Или выключите опцию.
Удержание не снимается Лог предупреждает об отклонённом вызове и называет оба объекта. Снимайте из объекта, который его поставил. Один тег — один владелец.
Экран не показывается Проверьте Loading Screen Mode и нет ли в запуске -NoLoadingScreen. В ручных режимах показ идёт только по Push Loading Screen. Выберите подходящий режим или вызовите Push Loading Screen.
Экран не анимируется в редакторе PIE не рисует через MoviePlayer. Проверьте в Standalone, в -game или в упакованной сборке. См. Ограничения.
Мой виджет замирает при загрузке карты В виджете привязка, Blueprint OnPaint, список или Retainer Box. Уберите их. Причину называет предупреждение компиляции.
Экран долго держится при первом запуске Идёт предкомпиляция PSO. Задайте Load Status Max PSO Wait Secs. См. Прогресс и PSO.
Rich Text показывает сырые теги Use Rich Text выключен или стиль неизвестен. Включите Use Rich Text и добавьте стиль в Rich Text Styles.
Контент Game Feature не виден Game Feature активирован после переезда. Активируйте его до переезда. Проверьте Enable Game Feature Actions.
