SGC Loading Background (перевод отсутствует)

Заголовок раздела «SGC Loading Background (перевод отсутствует)»

Картинка слайда: показывает фоны из Add Loading Backgrounds в перемешанном порядке без повторов и плавно переходит к следующему. Слайд меняется вместе с SGC Loading Tip: держится наибольший из их интервалов и время на чтение текста. Картинки загружаются, только пока этот виджет на экране.
