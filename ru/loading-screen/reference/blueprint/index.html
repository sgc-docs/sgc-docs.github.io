USGCAsync Action Wait for All Players (перевод отсутствует)

Заголовок раздела «USGCAsync Action Wait for All Players (перевод отсутствует)»

Ждёт, пока сервер сообщит, что все игроки загрузили текущую карту (Wait For All Players).

SGC|Loading Screen

Заголовок раздела «SGC|Loading Screen»

Wait For All Players Ready (перевод отсутствует)

Заголовок раздела «Wait For All Players Ready (перевод отсутствует)»

Waits until all players have loaded the current map, then fires On Ready. Call it after the map has loaded, for example before Dismiss Loading Screen in the manual modes. Fires at once when Wait For All Players is off or the game is not networked. Timed Out: the server stopped waiting because some players did not load in time. On a dedicated server, waits for the server’s current map readiness and uses only the server’s player wait timeout. If no player wait has started, keeps waiting until one starts or the world is cleaned up. World cleanup ends the wait without firing On Ready. (перевод отсутствует)

USGCAsync Action Wait Loading Screen Shown (перевод отсутствует)

Заголовок раздела «USGCAsync Action Wait Loading Screen Shown (перевод отсутствует)»

Waits for the current pending request, or the next request when idle, to show its screen. (перевод отсутствует)

SGC|Loading Screen

Заголовок раздела «SGC|Loading Screen»

Wait For Loading Screen Shown (перевод отсутствует)

Заголовок раздела «Wait For Loading Screen Shown (перевод отсутствует)»

Waits until the current pending request is shown; when idle, waits for the next request. An already visible or fading screen succeeds on the next frame with its captured request context. Cancellation before showing, failure to create a screen, and an unavailable screen subsystem use On Not Shown. A dedicated server is Unavailable. No timeout is applied. Showing does not mean loading has completed. (перевод отсутствует)

USGCAsync Action Watch PSOPrecompile (перевод отсутствует)

Заголовок раздела «USGCAsync Action Watch PSOPrecompile (перевод отсутствует)»

Следит за предкомпиляцией PSO (графические конвейеры под эту видеокарту и драйвер; долго при первом запуске сборки). Плагин не держит из-за неё игроков: решает ваша игра, например показывает уведомление или предупреждает перед «Новой игрой».

SGC|Loading Screen|PSO

Заголовок раздела «SGC|Loading Screen|PSO»

Watch PSO Precompile (перевод отсутствует)

Заголовок раздела «Watch PSO Precompile (перевод отсутствует)»

On Started: идёт предкомпиляция (Total — сколько PSO оставалось, когда наблюдение началось). On Progress: Remaining и Progress (0..1), не чаще 10 раз в секунду. On Finished: предкомпилировать больше нечего (Seconds — сколько длилось наблюдение). Срабатывает при первой проверке (0,1 с), если сейчас ничего не идёт.

Push Loading Screen (перевод отсутствует)

Заголовок раздела «Push Loading Screen (перевод отсутствует)»

Requests the loading screen for the current game instance. Available in every mode. A visible request is kept; an ordinary dismiss fade is cancelled. A fade forced by Max Visible Secs cannot be cancelled; request a new screen after it finishes. (перевод отсутствует)

Dismiss Loading Screen (перевод отсутствует)

Заголовок раздела «Dismiss Loading Screen (перевод отсутствует)»

Cancels a pending request, or fades out the visible screen even if loading or holds remain. With Continue On Input enabled, releases the manual gate instead: closing waits until loading reaches 100% and a new key, mouse button, gamepad button or touch confirms. Max Visible Secs can force closing. Available in every mode. Wait For Loading Screen Dismissed fires after the screen is removed. (перевод отсутствует)

Set Loading Screen Continue On Input (перевод отсутствует)

Заголовок раздела «Set Loading Screen Continue On Input (перевод отсутствует)»

Changes Continue On Input for this Game Instance without writing Project Settings. Applies to the visible screen and future requests. Disabling releases its continue gate immediately. When enabled, closing waits for new discrete input after 100% progress; in manual modes Dismiss must release the manual gate too. Repeats, analog input, console/PIE exceptions and MoviePlayer input do not confirm. Each network machine waits independently. Max Visible Secs still closes the screen. (перевод отсутствует)
