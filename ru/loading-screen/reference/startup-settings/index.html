Настройки стартового экрана

SGC Startup Loading Screen (перевод отсутствует)

Заголовок раздела «SGC Startup Loading Screen (перевод отсутствует)»

Настраивает стартовый экран загрузки, отображаемый во время инициализации движка.

Startup

Заголовок раздела «Startup»
Имя в редакторе Описание Значение по умолчанию Ограничения
Enable Startup Loading Screen (перевод отсутствует)
bEnableStartupLoadingScreen		 Включает стартовый экран загрузки в упакованных клиентских сборках. true —
Hold Screen Additional Secs (перевод отсутствует)
HoldScreenAdditionalSecs		 Дополнительное время показа страницы статуса после завершения стартовой работы. Статусный текст в это время уже скрыт. 0 Активно при — Enable Startup Loading Screen вкл.
Минимум — 0.0
Фиксированные единицы — s

Background

Заголовок раздела «Background»
Имя в редакторе Описание Значение по умолчанию Ограничения
Background Mode (перевод отсутствует)
BackgroundMode		 Выбирает для фона настраиваемый цвет или импортированное изображение. Color (перевод отсутствует) Активно при — Enable Startup Loading Screen вкл.
Background Image Path (перевод отсутствует)
BackgroundImagePath		 Путь к импортированному фоновому изображению относительно каталога Content проекта. пусто Расширенная настройка
Background Color (перевод отсутствует)
BackgroundColor		 Цвет фона, используемый только в режиме цвета. Чёрный (RGBA 0, 0, 0, 1) Активно при — Enable Startup Loading Screen вкл. и Background Mode = Color
Background Image Tint (перевод отсутствует)
BackgroundImageTint		 Оттенок, умножаемый на импортированное фоновое изображение. Белый (RGBA 1, 1, 1, 1) Активно при — Enable Startup Loading Screen вкл. и Background Mode = Image

Logo

Заголовок раздела «Logo»
Имя в редакторе Описание Значение по умолчанию Ограничения
Logo Image Path (перевод отсутствует)
LogoImagePath		 Путь к импортированному логотипу относительно каталога Content проекта. пусто Расширенная настройка
Logo Scale (перевод отсутствует)
LogoScale		 Размер логотипа относительно значения по умолчанию (0.4 ширины экрана, 0.25 высоты). 1 Активно при — Enable Startup Loading Screen вкл.
Минимум — 0.0
Максимум — 2.0
Минимум в UI — 0.0
Максимум в UI — 2.0
Logo Placement (перевод отсутствует)
LogoPlacement		 Независимое размещение логотипа. по центру / по центру, смещение (0, -0.12) Активно при — Enable Startup Loading Screen вкл.

Animation

Заголовок раздела «Animation»
Имя в редакторе Описание Значение по умолчанию Ограничения
Show Throbber (перевод отсутствует)
bShowThrobber		 Показывает анимацию загрузки, пока активна страница статуса. true Активно при — Enable Startup Loading Screen вкл.
Animation Style (перевод отсутствует)
AnimationStyle		 Procedural animation style, shared with SGC Loading Animation. (перевод отсутствует) Dots Circle (перевод отсутствует) Активно при — Enable Startup Loading Screen вкл. и Show Throbber вкл.
Animation Color (перевод отсутствует)
AnimationColor		 Main color of the loading animation. (перевод отсутствует) белый (RGBA 1, 1, 1, 1) Активно при — Enable Startup Loading Screen вкл. и Show Throbber вкл.
Animation Size (перевод отсутствует)
AnimationSize		 Animation size in design pixels at 1920x1080. (перевод отсутствует) (64, 64) Активно при — Enable Startup Loading Screen вкл. и Show Throbber вкл.
Минимум — 1.0
Animation Placement (перевод отсутствует)
AnimationPlacement		 Независимое размещение анимации. по центру / по центру, смещение (0, 0.18) Активно при — Enable Startup Loading Screen вкл. и Show Throbber вкл.

Progress

Заголовок раздела «Progress»
Имя в редакторе Описание Значение по умолчанию Ограничения
Show Progress (перевод отсутствует)
bShowProgress		 Shows estimated engine startup progress. 100% requires engine initialization and package, shader and PSO work to finish. (перевод отсутствует) false Активно при — Enable Startup Loading Screen вкл.
Progress Placement (перевод отсутствует)
ProgressPlacement		 Independent placement of the startup progress bar. (перевод отсутствует) по центру / по центру, смещение (0, 0.42) Активно при — Enable Startup Loading Screen вкл. и Show Progress вкл.
Progress Fill Color (перевод отсутствует)
ProgressFillColor		 Fill color of the startup progress bar. (перевод отсутствует) белый (RGBA 1, 1, 1, 1) Активно при — Enable Startup Loading Screen вкл. и Show Progress вкл.
Progress Width (перевод отсутствует)
ProgressWidth		 Progress bar width in design pixels at 1920x1080, limited by the available screen width. (перевод отсутствует) 640 Активно при — Enable Startup Loading Screen вкл. и Show Progress вкл.
Минимум — 1.0

Status Text

Заголовок раздела «Status Text»
Имя в редакторе Описание Значение по умолчанию Ограничения
Show Status Text (перевод отсутствует)
bShowStatusText		 Показывает доступный статус пакетов, ассетов, шейдеров и PSO. true Активно при — Enable Startup Loading Screen вкл.
Status Text Placement (перевод отсутствует)
StatusTextPlacement		 Независимое размещение текста статуса. по центру / по центру, смещение (0, 0.32) Активно при — Enable Startup Loading Screen вкл. и Show Status Text вкл.
Status Text Style (перевод отсутствует)
StatusTextStyle		 Стиль текста статуса загрузки. стандартный Regular 16, белый, смещение тени (1, -1), непрозрачность 0.6 Активно при — Enable Startup Loading Screen вкл. и Show Status Text вкл.

Tip

Заголовок раздела «Tip»
Имя в редакторе Описание Значение по умолчанию Ограничения
Show Tip (перевод отсутствует)
bShowTip		 Показывает необязательный текст подсказки. true Активно при — Enable Startup Loading Screen вкл.
Tip Text (перевод отсутствует)
TipText		 Необязательная локализуемая подсказка, отображаемая независимо от других элементов. пусто Активно при — Enable Startup Loading Screen вкл. и Show Tip вкл.
Tip Placement (перевод отсутствует)
TipPlacement		 Независимое размещение подсказки. по центру / снизу, смещение (0, -0.04) Активно при — Enable Startup Loading Screen вкл. и Show Tip вкл.
Tip Text Style (перевод отсутствует)
TipTextStyle		 Стиль необязательной подсказки. стандартный Regular 20, белый, смещение тени (1, -1), непрозрачность 0.6 Активно при — Enable Startup Loading Screen вкл. и Show Tip вкл.

Version

Заголовок раздела «Version»
Имя в редакторе Описание Значение по умолчанию Ограничения
Show Version (перевод отсутствует)
bShowVersion		 Показывает настроенную строку версии. true Активно при — Enable Startup Loading Screen вкл.
Version Display String (перевод отсутствует)
VersionDisplayString		 Текст версии. Если пусто, используется версия сборки приложения. пусто Активно при — Enable Startup Loading Screen вкл. и Show Version вкл.
Version Placement (перевод отсутствует)
VersionPlacement		 Независимое размещение версии. справа / сверху, смещение (-0.02, 0.02) Активно при — Enable Startup Loading Screen вкл. и Show Version вкл.
Version Text Style (перевод отсутствует)
VersionTextStyle		 Стиль текста версии. стандартный Regular 12, RGBA (0.8, 0.8, 0.8, 1), без тени Активно при — Enable Startup Loading Screen вкл. и Show Version вкл.

Movies

Заголовок раздела «Movies»
Имя в редакторе Описание Значение по умолчанию Ограничения
Movie Phase (перевод отсутствует)
MoviePhase		 Определяет, воспроизводятся ли ролики до или после страницы статуса загрузки. Disabled (перевод отсутствует) Активно при — Enable Startup Loading Screen вкл.
Movies Are Skippable (перевод отсутствует)
bMoviesAreSkippable		 Разрешает щелчком мыши или нажатием клавиши пропустить только активную фазу ролика. true Активно при — Enable Startup Loading Screen вкл. и Movie Phase ≠ Disabled
Startup Movie Paths (перевод отсутствует)
StartupMoviePaths		 Имена видео без расширения из Content/Movies. Импорт копирует файлы сразу; список воспроизведения и упаковка Non-UFS записываются при Save. пусто Расширенная настройка
