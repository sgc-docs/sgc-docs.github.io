Контент и подсказки

Страница про то, что показывает экран: фоны и подсказки. Нужен виджет с SGC Loading Background и SGC Loading Tip.

Добавление контента

Заголовок раздела «Добавление контента»

Используйте Add Loading Backgrounds (картинка мягкой ссылкой + свой текст по желанию) и Add Loading Tips.

  • Колода перетасована: каждый элемент раз за круг, каждый круг в новом порядке. После перезапуска круг продолжается.
  • Слайд держится наибольший интервал элементов и время на чтение текста (Reading Speed).
  • Картинки загружаются асинхронно, только пока экран их показывает, и выгружаются после закрытия.

Осторожно

Используйте непрозрачные картинки. Фон рисует альфа-канал картинки.

Наборы контента

Заголовок раздела «Наборы контента»

Набор контента — Data Asset SGC Loading Content Set. Перечислите его в Content Sets в Project Settings.

  • Набор хранит подсказки, String Table и фоны для выбранных карт.
  • Набор с пустым списком Maps — общий контент.
  • Для целевой карты действуют наборы с наибольшим Priority.
  • Replace Common скрывает общий контент.
  • Наборы попадают в cook автоматически.

В C++ наборы регистрирует SGCLoadingContent::RegisterSource. См. C++ API.

Fill by Names

Заголовок раздела «Fill by Names»

Fill by Names… находится в контекстном меню одного набора. Команда ищет в папке текстуры T_Loading_<Map> и T_Loading_<Map>_<N>, показывает предпросмотр и добавляет фоны одной выбранной карты.

Неоднозначные имена выбираются вручную. Команда только добавляет, поддерживает Undo и ассет не сохраняет.

Rich Text в подсказке

Заголовок раздела «Rich Text в подсказке»

Включите Use Rich Text (выкл. по умолчанию) у SGC Loading Tip и заполните Rich Text Styles. Текст Press <Key>E</> рисует E стилем Key.

Осторожно

Работают только текстовые стили: без картинок, ссылок и декораторов. Неизвестный стиль остаётся видимым текстом. Меняйте стили до показа блокирующего экрана загрузки.
