  • [1.0.1]
Документация описывает SGC Loading Screen 2.5.0, версия скоро появится на FAB. Сейчас на FAB — 1.0.0.

Что нового

Промежуточные версии между 1.0.0 и последней выпущенной версией не публиковались на FAB по отдельности.

[2.5.0] — 2026-11-16

Заголовок раздела «[2.5.0] — 2026-11-16»

Добавлено

Заголовок раздела «Добавлено»
  • Пресеты оформления Classic, Minimal и Cinematic. Выбираются при создании SGC Loading Screen Widget из Content Browser; на странице настроек стартового экрана Apply Preset меняет только оформление (анимацию, стили текста, полосу и размещения), на диск его пишет Save.
  • Стартовый экран: настройки Progress Fill Color и Progress Width.
  • Форматированный текст в подсказках. SGC Loading Tip: Use Rich Text (выключено по умолчанию) и Rich Text Styles — именованные стили текста для разметки вида Нажмите <Key>E</>. Только стили текста: без картинок, ссылок и декораторов. Неизвестный стиль остаётся видимым обычным текстом и пишет одно предупреждение в лог.
  • Fill by Names… в контекстном меню SGC Loading Content Set: находит в папке текстуры T_Loading_<Карта> и T_Loading_<Карта>_<N>, показывает их и добавляет в набор фоны одной выбранной карты (с Undo; ассет не сохраняется автоматически). Неоднозначные имена выбираются вручную.
  • Окно «Что нового» в редакторе: ссылки на документацию и видеообзор и изменения этой версии. Показывается при каждом запуске редактора, пока не отмечено Don’t show again; новая версия плагина показывает его снова. Открыть повторно — Help → SGC Loading Screen: What’s New.
  • Сайт документации https://sgc-docs.github.io/ru/loading-screen/ (русский и английский, поиск, быстрый старт, руководства и справочник, собранный из кода) вместо PDF-файлов. Его открывает ссылка Documentation плагина и окна «Что нового».

[2.4.0] — 2026-11-16

Заголовок раздела «[2.4.0] — 2026-11-16»

Добавлено

Заголовок раздела «Добавлено»
  • События и состояние экрана. Get Loading Screen Events возвращает объект с On Shown (Context), On Dismiss Started (Completion) и On Finished (Completion); Get Loading State (Unavailable, Idle, Pending, Visible, FadingOut); async-нода Wait For Loading Screen Shown (On Shown, On Not Shown с исходом). Исходы: Ready, Cancelled, Timed Out, Show Failed.
  • Max Visible Secs (0 — выключено): закрывает экран с исходом Timed Out через заданное число секунд после первого показа, поэтому забытый Dismiss больше не держит экран вечно.
  • Интерактивный экран. Виджеты экрана получают ввод и фокус, остальной ввод игры в его вьюпорте остаётся заблокированным; после закрытия фокус возвращается.
  • Continue On Input (по умолчанию выключено) и нода Set Loading Screen Continue On Input: после 100 % экран ждёт клавишу, клик мыши, кнопку геймпада или касание («Press any key to continue»). Работает во всех режимах, для одного игрока.
  • Wait For All Players Ready на dedicated server: ждёт результат серверной сессии текущего поколения.
  • Наборы контента. Data Asset SGC Loading Content Set (подсказки, String Table, фоны, карты, Add To Common / Replace Common, Priority), настройка Content Sets и C++ API регистрации SGCLoadingContent::RegisterSource / UnregisterSource. Контент выбирается по целевой карте; подсказки можно брать из String Table. Наборы попадают в cook автоматически.
  • Game Feature Action «Add Loading Content» в необязательном модуле SGCLoadingScreenGameFeatures (настройка Enable Game Feature Actions, нужен плагин GameFeatures и перезапуск).
  • Модуль SGCLoadingScreenSlate: Slate-виды и общие настройки оформления стартового и игрового экрана.
  • Reduce Motion: настройка проекта и выбор игрока (ноды Set / Get Loading Screen Reduce Motion, сохраняется в GameUserSettings.ini).
  • Стартовый экран: Animation Style, Animation Color, Animation Size, Show Progress (выкл.) и Progress Placement.

Изменено

Заголовок раздела «Изменено»
  • Add / Remove / Clear Loading Tips и Backgrounds меняют только свой источник: такой же элемент из набора остаётся, пока его держит другой источник.
  • Block Input While Visible блокирует ввод игры, но не виджеты экрана. Во время блокирующей загрузки карты (MoviePlayer) ввод игры поглощается всегда.
  • Стартовый экран рисует те же виды, что игровой: девять стилей анимации вместо движкового throbber (Show Throbber сохраняет имя), общий элемент статуса, необязательная полоса прогресса.
  • Новый фабричный вид стартового экрана: статус 16 (было 14), подсказка 20 белым (было 16, серый), тень текста. Сохранённые значения не меняются.
  • FSGCLoadingTextStyle перенесён в модуль SGCLoadingScreenSlate: редирект — в Config/DefaultSGCLoadingScreen.ini, прежний заголовок подключает новый, ключи ini те же.
  • Подсказки Push / Dismiss Loading Screen и Loading Screen Mode больше не упоминают скрытие нод.

Удалено

Заголовок раздела «Удалено»
  • Фильтр нод Blueprint в редакторе, скрывавший Push / Dismiss Loading Screen по режиму экрана: обе ноды показываются всегда.

[2.3.0] — 2026-11-15

Заголовок раздела «[2.3.0] — 2026-11-15»

Добавлено

Заголовок раздела «Добавлено»
  • Элемент SGC Loading Progress: честная полоса прогресса с необязательным процентом. Значение строится по фазам загрузки движка, удержаниям игры и истории длительности карты; 100 % значит, что экран можно закрывать. Работает при блокирующей загрузке карты (MoviePlayer).
  • Нода Get Loading Progress: показанный прогресс от 0 до 1 (без экрана — 0).
  • История длительности по картам в GameUserSettings.ini (секция SGCLoadingScreen.LoadHistory). Пишутся только успешные загрузки.
  • Финальный аккорд SGC Loading Animation: Finish Style — Ring (по умолчанию), Check, None; проигрывается в первые 0,3 с затухания.
  • Зум при затухании и настройка Dismiss Zoom Scale (1,04; 1 — выключено).
  • Строка статуса Preparing graphics for your GPU (N), когда в фазе PSO больше 100 PSO (и на стартовом экране).
  • Оверлей метрик: строка Holds: (тег, владелец, возраст). Удержание дольше 30 с даёт предупреждение в логе.
  • Страница стартовых настроек: надпись о несохранённых изменениях, уведомление после Save, кнопка Reload Saved.
  • Blueprint Set-узлы для 43 свойств SGC Loading Animation, Background, Tip и Load Status, а также для свойств SGC Loading Progress и Finish Style.
  • TestKit: команда SGCTest.Progress.

Изменено

Заголовок раздела «Изменено»
  • Порядок закрытия: загрузка завершена → включается рендер мира → ожидание свежего счётчика текстур (до Auto Dismiss Max Texture Streaming Wait Secs, теперь во всех режимах) → прогресс добегает до 100 % → затухание. Раньше рендер мира включался только в начале затухания.
  • Новое удержание игры или переезд во время затухания возвращает экран во всех режимах (раньше — только в автоматическом показе); счётчики движка — нет. Работа, появившаяся после 100 %, начинает новый отсчёт полосы.
  • Фабричный макет и встроенный экран: полоса прогресса под статусом. Существующие Widget Blueprint не меняются: добавьте элемент вручную (см. RELEASE_NOTES.md).
  • Затухание и зум применяются к контейнеру плагина вокруг вашего виджета, а не к самому виджету.

Устарело

Заголовок раздела «Устарело»
  • Waiting Status Text теперь WaitingStatusText_DEPRECATED и скрыта из Project Settings. Ключ ini прежний; значение по-прежнему уходит в устаревшее событие Level Load Status. Вместо неё используйте Idle Text элемента SGC Load Status.

[2.2.3] — 2026-11-15

Заголовок раздела «[2.2.3] — 2026-11-15»

Исправлено

Заголовок раздела «Исправлено»
  • Слайды при блокирующей загрузке карты: экран передаётся в MoviePlayer только с готовым первым слайдом. В памяти только текущий и следующий слайд; если следующий не успел, текущий начинает новый круг (зум идёт в обратную сторону, без перехода и анимации текста), а как только следующий готов — обычная смена.
  • Макет встроенного экрана и фабрики: Tip и Load Status в общей вертикальной колонке — многострочный статус не перекрывает подсказку.
  • После лимита Load Status Max PSO Wait Secs строка статуса сообщает, что PSO компилируются в фоне (PSO compiling in background: N), и экран больше не выглядит ожидающим.
  • Wait For All Players: клиент, вошедший или закончивший загрузку после таймаута, получает событие таймаута в виджете (раньше — только исход Timed Out у ноды Wait For All Players Ready). Если экрана в этот момент нет, событие получит первый показ на этой карте; переезд или переподключение его сбрасывает.
  • Wait For All Players: сервер брал таймаут без минимума 1 с, который применяли клиент и нода; теперь у всех троих одно значение.
  • Подсказки Wait For All Players, Load Status Complete Delay Secs, Load Status Max PSO Wait Secs и класса SGC Loading Screen Widget больше не опираются на устаревшее событие Level Load Status; Waiting Status Text сообщает, что действует только для него.

Изменено

Заголовок раздела «Изменено»
  • SGC Loading Animation, SGC Loading Background, SGC Loading Tip и SGC Load Status: свойства в C++ закрыты, используйте функции Get/Set (GetFont, SetFont, …). Имена, значения по умолчанию и Details не изменились; в Blueprint свойства по-прежнему только для чтения, ноды Get работают.
  • Project Settings: значки предупреждения у Fast PSO Precompile While Visible, Load Status Max PSO Wait Secs (при значении больше 0), Wait For All Players и переключателя стартового экрана; подсказка говорит, что перезапустить и где проверять.
  • C++: FOnSGCStartupLoadingScreenSettingsChanged устарел, используйте FSGCStartupLoadingScreenSettingsChangedDelegate. USGCLoadingScreenSettings::bManualLoadingScreen теперь bManualLoadingScreen_DEPRECATED (ключ ini прежний и по-прежнему переносится в режим).
  • Уже созданные Widget Blueprint сохраняют свой макет. Чтобы получить новый, добавьте Vertical Box внизу контентного Overlay экрана, поместите в него Tip и Load Status и задайте Tip нижний отступ.
  • Внутренняя уборка без смены поведения: комментарии, инклуды и зависимости модулей, поля Transient, имена, мёртвый код, один общий StreamableManager, анимация Arc без покадровых массивов.

[2.2.2] — 2026-11-10

Заголовок раздела «[2.2.2] — 2026-11-10»

Исправлено

Заголовок раздела «Исправлено»
  • Удержание, поставленное во время затухания, в режимах автопоказа возвращает экран (раньше экран закрывался).
  • Dismiss и Push из Construct виджета экрана или из обработчика On Holds Changed больше не ломают состояние: у запроса экрана есть идентичность, старое продолжение не действует на новый запрос.
  • Неудачная загрузка карты закрывает только свою загрузку: удержание «Loading level» не зависает; загрузка другого Game Instance не влияет на экран.
  • Класс Loading Screen Widget не загрузился или не создаётся: встроенный экран и одна ошибка в лог (раньше экран не появлялся).
  • Отложенный колбэк загрузки класса виджета снимается вместе с загрузкой.
  • Экран, отданный MoviePlayer на время загрузки карты: тики Blueprint возвращаются только после остановки потока загрузки; удержания, поставленные кодом игры во время загрузки, обновляют экран после его возврата.
  • Fast PSO Precompile при нескольких Game Instance: режим возвращается, когда закрыт последний экран.
  • Wait For All Players: смена сервера (счётчики привязаны к подключению); таймаут сервера по реальному времени (не зависит от паузы и замедления); сервер различает «все готовы» и «таймаут»; начальный мир PIE.
  • Стартовый экран: несколько Movie Streamer (выбирается первый успешно инициализированный, регистрация другого не меняет играющий), очистка после неудачной инициализации, при ошибке защиты изменения размера окна — запасной оконный полноэкранный режим.
  • Счётчик PSO для стартового экрана и статуса во время загрузки карты читается на потоке рендера и публикуется атомарно; счётчик шейдеров с других потоков — только локальные задания.
  • Фоны слайдов: неготовая картинка не показывается никогда (обход «показать через 3 секунды» убран); картинка, не ставшая готовой за 10 с, пропускается до следующего круга; подготовка первого кадра — один общий бюджет времени.
  • Watch PSO Precompile: тикер снимается до On Finished; нода переживает завершение из своих же событий.

Изменено

Заголовок раздела «Изменено»
  • Удержания: один тег — один владелец. Обновить и снять удержание может только поставивший его объект; чужой вызов отклоняется с предупреждением, где названы оба объекта. Удержание уничтоженного владельца не учитывается сразу.
  • Работа по требованию: статичный экран ручного закрытия после завершения загрузки не тикает; контент слайдов работает, только пока его элементы рисуются (скрытый сохранённый виджет больше не держит загрузку фонов); сервер ожидания игроков и нода Wait For All Players Ready — на событиях, без покадрового тикера; оверлей в режиме «только память» — по таймеру.
  • Wait For All Players Ready читает таймаут один раз, в начале ожидания.
  • Лог: переходы состояний экрана (Verbose) с причиной, картой и номером запроса; SGC.LoadingScreen.Why показывает фазу загрузки и номер запроса.
  • C++: FSGCLoadWorkSnapshot::CaptureThreadSafe переименована в CaptureFromAnyThread; добавлены FSGCPSOStatus и FSGCPSOStatusSubscription (модуль Core).

[2.2.1] — 2026-11-09

Заголовок раздела «[2.2.1] — 2026-11-09»

Изменено

Заголовок раздела «Изменено»
  • Внутренняя уборка без изменения поведения: одно состояние для видео стартового экрана, SGC Loading Screen Widget создаётся через фабрику Widget Blueprint движка, внутренние заголовки перенесены в Private, автотесты для удержаний, строк статуса и решения об автозакрытии.
  • README: какой C++ API стабилен.

[2.2.0] — 2026-11-07

Заголовок раздела «[2.2.0] — 2026-11-07»

Добавлено

Заголовок раздела «Добавлено»
  • Экран не замирает во время блокирующей загрузки карты: его рисует MoviePlayer в потоке загрузки, анимация, слайды и подсказки продолжают двигаться, ваш UMG показан статично. Настройка Keep Elements Alive During Map Load (по умолчанию включена). Игра, Standalone и упакованная сборка; не в редакторе и PIE.
  • Предупреждение при компиляции экрана с привязками свойств, Blueprint OnPaint, списками или Retainer Box: такой экран во время загрузки карты стоит неподвижно.
  • Значок предупреждения у Keep Elements Alive During Map Load в Project Settings: в редакторе и PIE эффект не виден.
  • Консольная переменная SGC.LoadingScreen.SimulateMapLoadSecs (сборки для разработки): удлиняет каждую загрузку карты, чтобы посмотреть экран на долгой загрузке.

Исправлено

Заголовок раздела «Исправлено»
  • Стартовый экран: числа не менялись весь запуск движка.
  • SGC Loading Background: скачок картинки на один кадр при смене слайдов с разными пропорциями.
