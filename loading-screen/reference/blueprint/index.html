Blueprint API

USGCAsync Action Wait for All Players

Section titled “USGCAsync Action Wait for All Players”

Waits until the server reports that every player has loaded the current map (Wait For All Players).

SGC|Loading Screen

Section titled “SGC|Loading Screen”

Wait For All Players Ready

Section titled “Wait For All Players Ready”

Waits until all players have loaded the current map, then fires On Ready. Call it after the map has loaded, for example before Dismiss Loading Screen in the manual modes. Fires at once when Wait For All Players is off or the game is not networked. Timed Out: the server stopped waiting because some players did not load in time. On a dedicated server, waits for the server’s current map readiness and uses only the server’s player wait timeout. If no player wait has started, keeps waiting until one starts or the world is cleaned up. World cleanup ends the wait without firing On Ready.

ReturnValue USGCAsyncAction_WaitForAllPlayers* output — —

USGCAsync Action Wait Loading Screen Shown

Section titled “USGCAsync Action Wait Loading Screen Shown”

Waits for the current pending request, or the next request when idle, to show its screen.

SGC|Loading Screen

Section titled “SGC|Loading Screen”

Wait For Loading Screen Shown

Section titled “Wait For Loading Screen Shown”

Waits until the current pending request is shown; when idle, waits for the next request. An already visible or fading screen succeeds on the next frame with its captured request context. Cancellation before showing, failure to create a screen, and an unavailable screen subsystem use On Not Shown. A dedicated server is Unavailable. No timeout is applied. Showing does not mean loading has completed.

Parameter Type Direction Default Note
ReturnValue USGCAsyncAction_WaitLoadingScreenShown* output — —

USGCAsync Action Watch PSOPrecompile

Section titled “USGCAsync Action Watch PSOPrecompile”

Watches PSO precompilation (graphics pipelines prepared for this GPU and driver; long on the first run of a build). The plugin does not hold players for it: your game decides, for example shows a notice or warns before New Game.

SGC|Loading Screen|PSO

Section titled “SGC|Loading Screen|PSO”

Watch PSO Precompile

Section titled “Watch PSO Precompile”

On Started: precompilation is running (Total: PSOs left when watching started). On Progress: Remaining and Progress (0..1), at most 10 times per second. On Finished: nothing is left to precompile (Seconds watched). Fires at the first check (0.1 s) if nothing runs now.

Parameter Type Direction Default Note
ReturnValue USGCAsyncAction_WatchPSOPrecompile* output — —

USGCLoading Screen Blueprint Library

Section titled “USGCLoading Screen Blueprint Library”

Blueprint access to the game-instance loading screen.

SGC|Loading Screen

Section titled “SGC|Loading Screen”

Push Loading Screen

Section titled “Push Loading Screen”

Requests the loading screen for the current game instance. Available in every mode. A visible request is kept; an ordinary dismiss fade is cancelled. A fade forced by Max Visible Secs cannot be cancelled; request a new screen after it finishes.

Dismiss Loading Screen

Section titled “Dismiss Loading Screen”

Cancels a pending request, or fades out the visible screen even if loading or holds remain. With Continue On Input enabled, releases the manual gate instead: closing waits until loading reaches 100% and a new key, mouse button, gamepad button or touch confirms. Max Visible Secs can force closing. Available in every mode. Wait For Loading Screen Dismissed fires after the screen is removed.

Get Loading Screen Events

Section titled “Get Loading Screen Events”

Returns the Game Instance event source for shown, dismiss-started and finished notifications. Null when screens are unavailable.

Parameter Type Direction Default Note
ReturnValue USGCLoadingScreenEvents* output — —

Get Loading State

Section titled “Get Loading State”

Returns Unavailable without a screen subsystem (including a dedicated server), otherwise its current lifecycle state.

Parameter Type Direction Default Note
ReturnValue ESGCLoadingScreenState output — —

Set Loading Screen Continue On Input

Section titled “Set Loading Screen Continue On Input”

Changes Continue On Input for this Game Instance without writing Project Settings. Applies to the visible screen and future requests. Disabling releases its continue gate immediately. When enabled, closing waits for new discrete input after 100% progress; in manual modes Dismiss must release the manual gate too. Repeats, analog input, console/PIE exceptions and MoviePlayer input do not confirm. Each network machine waits independently. Max Visible Secs still closes the screen.

Parameter Type Direction Default Note
bEnabled bool input — —

SGC|Loading Screen|Holds

Section titled “SGC|Loading Screen|Holds”

Set Loading Screen Hold

Section titled “Set Loading Screen Hold”

Keeps the loading screen visible for a reason of your game (for example LoadingScreen.Hold.Quests), with an optional progress (0..1, -1 = unknown) and status line. Calling it again with the same reason updates the progress and the text. In the automatic show modes it also shows the screen. The calling object owns the hold: if it is destroyed, the hold is released (with a warning in the log).

Parameter Type Direction Default Note
Reason FGameplayTag input — —
Progress float input -1 —
StatusText const FText&amp; input — Advanced pin

Advanced — StatusText

SGC|Loading Screen|Slides

Section titled “SGC|Loading Screen|Slides”

Add Loading Tips

Section titled “Add Loading Tips”

Adds tips for SGC Loading Tip. Each tip is shown once per round, in a new order each round; the round continues after a game restart. A tip already in the list is not added twice. Selected Replace Common content sets hide these tips for their destination maps.

Parameter Type Direction Default Note
Tips const TArray&lt;FText&gt;&amp; input — —

Remove Loading Tips

Section titled “Remove Loading Tips”

Removes tips added by Add Loading Tips. Matching tips from content sets remain. A removed tip shown now is replaced at once.

Parameter Type Direction Default Note
Tips const TArray&lt;FText&gt;&amp; input — —

Clear Loading Tips

Section titled “Clear Loading Tips”

Removes all tips added by Add Loading Tips. Tips from content sets remain.

Add Loading Backgrounds

Section titled “Add Loading Backgrounds”

Adds backgrounds for SGC Loading Background: an image and an optional text of its own. Images load in the background only while the loading screen shows them; one that fails to load is removed. Each background is shown once per round, in a new order each round; the round continues after a game restart. Selected Replace Common content sets hide these backgrounds for their destination maps.

Parameter Type Direction Default Note
Backgrounds const TArray&lt;FSGCLoadingBackground&gt;&amp; input — —

Remove Loading Backgrounds

Section titled “Remove Loading Backgrounds”

Removes backgrounds added by Add Loading Backgrounds. Matching backgrounds from content sets remain. A removed background shown now is replaced at once.

Parameter Type Direction Default Note
Backgrounds const TArray&lt;FSGCLoadingBackground&gt;&amp; input — —

Clear Loading Backgrounds

Section titled “Clear Loading Backgrounds”

Removes all backgrounds added by Add Loading Backgrounds. Backgrounds from content sets remain.
