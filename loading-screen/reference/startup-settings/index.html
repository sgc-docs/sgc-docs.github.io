Startup settings

SGC Startup Loading Screen

Section titled “SGC Startup Loading Screen”

Configures the startup loading screen shown during engine initialization.

Startup

Section titled “Startup”
Editor name Description Default Constraints
Enable Startup Loading Screen
bEnableStartupLoadingScreen		 Enables the startup loading screen in packaged clients. true —
Hold Screen Additional Secs
HoldScreenAdditionalSecs		 Additional time to keep the status page visible after startup work has completed. Status text is already hidden during this hold. 0 Active when — Enable Startup Loading Screen on
Minimum — 0.0
Fixed units — s

Background

Section titled “Background”
Editor name Description Default Constraints
Background Mode
BackgroundMode		 Selects a configurable color or an imported image for the background. Color Active when — Enable Startup Loading Screen on
Background Image Path
BackgroundImagePath		 Imported background image path relative to the project Content directory. — Advanced
Background Color
BackgroundColor		 Background color used only in Color mode. Black (RGBA 0, 0, 0, 1) Active when — Enable Startup Loading Screen on and Background Mode = Color
Background Image Tint
BackgroundImageTint		 Tint multiplied with the imported background image. White (RGBA 1, 1, 1, 1) Active when — Enable Startup Loading Screen on and Background Mode = Image

Logo

Section titled “Logo”
Editor name Description Default Constraints
Logo Image Path
LogoImagePath		 Imported logo image path relative to the project Content directory. — Advanced
Logo Scale
LogoScale		 Logo size relative to the default (0.4 of screen width, 0.25 of screen height). 1 Active when — Enable Startup Loading Screen on
Minimum — 0.0
Maximum — 2.0
UI minimum — 0.0
UI maximum — 2.0
Logo Placement
LogoPlacement		 Independent logo placement. Center / Center, offset (0, -0.12) Active when — Enable Startup Loading Screen on

Animation

Section titled “Animation”
Editor name Description Default Constraints
Show Throbber
bShowThrobber		 Shows the loading animation while the status page is active. true Active when — Enable Startup Loading Screen on
Animation Style
AnimationStyle		 Procedural animation style, shared with SGC Loading Animation. Dots Circle Active when — Enable Startup Loading Screen on and Show Throbber on
Animation Color
AnimationColor		 Main color of the loading animation. white (RGBA 1, 1, 1, 1) Active when — Enable Startup Loading Screen on and Show Throbber on
Animation Size
AnimationSize		 Animation size in design pixels at 1920x1080. (64, 64) Active when — Enable Startup Loading Screen on and Show Throbber on
Minimum — 1.0
Animation Placement
AnimationPlacement		 Independent animation placement. Center / Center, offset (0, 0.18) Active when — Enable Startup Loading Screen on and Show Throbber on

Progress

Section titled “Progress”
Editor name Description Default Constraints
Show Progress
bShowProgress		 Shows estimated engine startup progress. 100% requires engine initialization and package, shader and PSO work to finish. false Active when — Enable Startup Loading Screen on
Progress Placement
ProgressPlacement		 Independent placement of the startup progress bar. Center / Center, offset (0, 0.42) Active when — Enable Startup Loading Screen on and Show Progress on
Progress Fill Color
ProgressFillColor		 Fill color of the startup progress bar. white (RGBA 1, 1, 1, 1) Active when — Enable Startup Loading Screen on and Show Progress on
Progress Width
ProgressWidth		 Progress bar width in design pixels at 1920x1080, limited by the available screen width. 640 Active when — Enable Startup Loading Screen on and Show Progress on
Minimum — 1.0

Status Text

Section titled “Status Text”
Editor name Description Default Constraints
Show Status Text
bShowStatusText		 Shows available package, asset, shader, and PSO status. true Active when — Enable Startup Loading Screen on
Status Text Placement
StatusTextPlacement		 Independent status text placement. Center / Center, offset (0, 0.32) Active when — Enable Startup Loading Screen on and Show Status Text on
Status Text Style
StatusTextStyle		 Style used by loading status text. default Regular 16, white, shadow offset (1, -1), opacity 0.6 Active when — Enable Startup Loading Screen on and Show Status Text on

Tip

Section titled “Tip”
Editor name Description Default Constraints
Show Tip
bShowTip		 Shows the optional tip text. true Active when — Enable Startup Loading Screen on
Tip Text
TipText		 Optional localized tip displayed independently of other elements. — Active when — Enable Startup Loading Screen on and Show Tip on
Tip Placement
TipPlacement		 Independent tip placement. Center / Bottom, offset (0, -0.04) Active when — Enable Startup Loading Screen on and Show Tip on
Tip Text Style
TipTextStyle		 Style used by the optional tip. default Regular 20, white, shadow offset (1, -1), opacity 0.6 Active when — Enable Startup Loading Screen on and Show Tip on

Version

Section titled “Version”
Editor name Description Default Constraints
Show Version
bShowVersion		 Shows the configured version string. true Active when — Enable Startup Loading Screen on
Version Display String
VersionDisplayString		 Version text. Empty uses the application build version. — Active when — Enable Startup Loading Screen on and Show Version on
Version Placement
VersionPlacement		 Independent version placement. Right / Top, offset (-0.02, 0.02) Active when — Enable Startup Loading Screen on and Show Version on
Version Text Style
VersionTextStyle		 Style used by version text. default Regular 12, RGBA (0.8, 0.8, 0.8, 1), no shadow Active when — Enable Startup Loading Screen on and Show Version on

Movies

Section titled “Movies”
Editor name Description Default Constraints
Movie Phase
MoviePhase		 Selects whether movies play before or after the loading status page. Disabled Active when — Enable Startup Loading Screen on
Movies Are Skippable
bMoviesAreSkippable		 Allows a mouse click or key press to skip only the active movie phase. true Active when — Enable Startup Loading Screen on and Movie Phase ≠ Disabled
Startup Movie Paths
StartupMoviePaths		 Extensionless movie names from Content/Movies. Import copies files immediately; the playlist and Non-UFS packaging are written on Save. — Advanced
