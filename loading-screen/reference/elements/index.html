SGC Loading Animation

Section titled “SGC Loading Animation”

Procedural loading animation: choose a style and tune it in Details. No textures or materials needed.

SGC Loading Background

Section titled “SGC Loading Background”

Slide image: shows the backgrounds from Add Loading Backgrounds in a shuffled order without repeats and cross-fades to the next one. The slide changes together with SGC Loading Tip: it stays for the longest interval of the two and for the time needed to read its text. Images load only while this widget is on screen.

Background

Section titled “Background”
Editor name Description Default Constraints
Change Interval Secs
ChangeIntervalSecs		 The image stays at least this long. 0: this widget does not change slides. 10 Minimum — 0.0
Fixed units — s
Get node — GetChangeIntervalSecs
Set node — SetChangeIntervalSecs
Fade Secs
FadeSecs		 Cross-fade time when the image changes. 0: instant. 1 Minimum — 0.0
Fixed units — s
Get node — GetFadeSecs
Set node — SetFadeSecs
Zoom Amount
ZoomAmount		 Slow zoom of each image: in and out by turns, drifting along a new diagonal. 0.08 = 8 %. 0: still image. 0.08 Minimum — 0.0
Maximum — 0.5
Get node — GetZoomAmount
Set node — SetZoomAmount
Default Image
DefaultImage		 Shown until the first image loads and while the background list is empty (also in the designer). Empty brush with black tint Get node — GetDefaultImage
Set node — SetDefaultImage

SGC Loading Progress

Section titled “SGC Loading Progress”

Loading progress estimated from engine phases, game holds and map duration history. 100% means the screen can close. Late work starts a new cycle from zero.

SGC Loading Tip

Section titled “SGC Loading Tip”

Slide text: the tip of the background shown now, otherwise the next tip from Add Loading Tips, in a shuffled order without repeats. Changes together with SGC Loading Background; works on its own when there is none. Place it anywhere in the loading screen, also inside other panels.

Get node — GetReadingSpeed

RichTextStyles		 Named styles for rich text tags, for example Key in <Key>E</>. Unknown or unclosed tags remain visible as text. Positive Shadow Y moves the shadow up. Shadow Blur controls black shadow opacity. Set styles before showing a blocking loading screen. — Active when — Use Rich Text on

SGC Load Status

Section titled “SGC Load Status”

Status lines of the loading screen: one line per hold (level, packages, assets, shaders, PSOs, players and your own holds with their progress). Place it inside any widget; no Blueprint logic is needed. Lines change with the holds; the dots and the package, shader and PSO counts stay alive during a map load too. Takes no space when there is nothing to show.
